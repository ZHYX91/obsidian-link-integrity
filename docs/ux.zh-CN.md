# Link Integrity UX 规范

## 1. 交互目标

Link Integrity 是只读诊断工具。界面应让用户先理解问题、再导航到来源或目标；它不提供批量删除、自动改写或暗示“安全清理”的操作。所有计数和标签都必须保持以下区别：

- 无效链接是引用 occurrence 级诊断；同一目标的多处引用可以分别定位。
- 孤立文件是有效显式链接图的文件级投影。
- 预期孤立是用户规则命中的独立状态，不是虚构的图连接。
- “孤立 · 含 N 处无效链接”是低置信度结果，不得显示为高置信度清理候选。
- 候选范围、诊断可见性与图贡献范围是三个独立概念。

插件在桌面和移动端使用同一产品语义。窄屏可以改变布局，但不能隐藏关键状态或改变计数含义。

## 2. 侧栏信息架构

侧栏以两个业务页签开始，不重复显示插件标题，也不常驻“刷新 / 设置”操作行。插件设置只从 Obsidian 的插件设置页进入。用户可以在两个业务页签间切换：

1. **无效链接**：显示当前可见 occurrence 数量。
2. **孤立文件**：显示当前主投影数量；默认不包含预期孤立文件。

结果就绪时不占用固定状态行。扫描进度只在扫描期间显示；结果过期或重建失败时，在当前面板内显示状态和“重试重建”操作。尚无 baseline 时，打开侧栏会自动开始首次完整建立，同时保留一个可发现的“建立索引”操作。全量重建失败时不得用空列表覆盖 last-known-good 结果。

结果 DOM 每页固定不超过 200 个 occurrence 或文件。上一页/下一页可遍历完整的筛选与排序结果；页签徽标始终保留全量计数，范围标签标明当前页。搜索、排序、分组、视图、模式、预期孤立显示或文件类型筛选改变时回到第一页。

工具栏的视觉层级必须与操作频率一致：搜索框独占可用主宽度，列表/树或分组/列表是主要视图切换，排序则显示为带“排序”文本标签的紧凑下拉框。窄侧栏可以换行并增大触控高度，但不得把排序下拉框拉伸成与主视图切换同宽的整行按钮；选项使用“按路径、按文件名、按修改时间”等明确排序含义。

### 2.1 无效链接页签

默认按目标分组，也可切换为按来源分组或 occurrence 列表。每项至少显示来源、原始引用、问题类型和可用的位置提示。

- 文件目标缺失、标题缺失和块缺失使用不同标签。
- 目标文件存在而子路径缺失时，仍允许打开目标文件，同时保留子路径诊断。
- Markdown 正文尽可能定位到行；Frontmatter、Canvas 和 Bases 在宿主 API 无法提供稳定精确位置时，诚实降级为打开来源文件或节点。
- 行菜单可以基于当前 occurrence、目标或来源创建忽略规则。保存前显示规则作用范围和匹配预览；保存后提供一次可撤销入口。

搜索、分组、排序和“显示已忽略”只改变当前投影，不改变底层图。

### 2.2 孤立文件页签

用户可以在列表和文件夹树之间切换，并按名称、路径或修改时间排序。结果分为：

- 普通孤立：没有与其他现有 Vault 文件相连的有效入链或出链。
- 低置信度孤立：仍是孤立文件，但含有一处或多处无效出链。
- 预期孤立：命中启用的预期孤立规则；默认从主计数和高置信度投影排除。

“显示预期孤立文件”是高级查看开关。开启后，预期孤立文件必须带独立标记，不能混同普通结果。预期孤立规则不隐藏这些文件的无效链接。

“无入链文件”只作为高级投影出现，并须明确说明它不同于默认孤立判定。

## 3. 文件类型筛选

默认候选类型在设置中持久化，侧栏中的选择只是当前查询筛选。一级分类与二级格式族如下：

- Obsidian 文件：Markdown、Bases、Canvas。
- 图片：JPEG、PNG、TIFF、GIF、WebP、AVIF、BMP、SVG、HEIF/HEIC 等格式族。
- 音频：FLAC、M4A/AAC、MP3、OGG、WAV、WebM、3GP 等格式族。
- 视频：MKV、MOV、MP4/M4V、OGV、WebM 等格式族。
- 版式文件：PDF。
- 其他附件：预置格式族和自定义扩展名。

扩展名匹配不区分大小写，别名合并为一个格式族。一级分类支持全选、清除、恢复默认和半选状态；二级菜单只用于需要精细控制的用户。WebM 等可属于多个媒体能力分类的格式须保留全部分类身份，筛选不能因单一主分类而漏项。

筛选后的计数显示为“可见数 / 配置范围总数”，避免用户把临时隐藏误解为重新计算图。

## 4. 设置界面

设置分为三个页签：常规、无效链接、孤立文件。Obsidian 1.12 的命令式设置 UI 与 1.13 及之后的声明式/可搜索设置 UI 共用同一组定义、值来源和副作用，不允许形成两套语义。

### 4.1 常规

- 语言：跟随 Obsidian 或 11 个内置语言之一。
- 默认侧栏页签与启动时扫描。
- 链接索引状态及手动重建操作；重建用于异常恢复或完整核对，不是日常刷新要求。

语言切换立即更新插件界面。“跟随 Obsidian”保留内部稳定值 `auto`，但用户可见术语必须明确表达宿主关系。设置搜索、键盘导航和状态文本都使用当前语言；11 个内置 catalog 必须在编译期完整覆盖稳定消息键，不依赖英文拼接补齐，也不得显示内部键名。

### 4.2 无效链接

- 默认分组和排序。
- 可见诊断类型。
- 无效链接专属忽略规则及匹配预览。
- 显示已忽略结果的调试入口。

### 4.3 孤立文件

- 默认候选文件分类和格式族。
- 默认列表/树视图及排序。
- 孤立候选忽略规则。
- 预期孤立规则及周期笔记预设。
- “显示预期孤立”和“无入链”高级投影。
- 排除图贡献的高级规则；必须在保存前警告它可能制造假孤立结果。

## 5. 规则编辑与预览

忽略规则和预期孤立规则都要在保存前预览。预览包含匹配数量及有限样例，并绑定当前规则草稿和索引 revision；较旧异步结果不得覆盖较新的编辑。

已保存的预期孤立规则默认显示为紧凑摘要卡，包含启停、名称、范围摘要和编辑入口，不直接铺开完整规则引擎。添加入口先提供周期笔记、文件夹、命名模式和高级自定义意图；周期笔记入口转到独立预设，其余入口打开模态草稿编辑器。编辑器对草稿自动防抖预览，只有“保存”才提交设置；“取消”、Esc 或关闭遮罩必须丢弃草稿。规则删除位于编辑器内，不能与普通预览操作并列成为主视觉动作。

预期孤立规则具有名称、启停状态和组合条件：

- 文件类型或格式族；
- 文件夹精确范围或递归范围；
- basename 或完整路径上的日期格式、glob 或高级正则。

不同条件组按 AND 组合，同一命名条件中的多个模式按 OR 组合。内置周期笔记预设包含可配置的日、周、月、季、年模式：`YYYY-MM-DD`、`GGGG-[W]WW`、`YYYY-MM`、`YYYY-[Q]Q`、`YYYY`。该预设只生成本插件规则，不读取 Chrono Notes 的数据或代码。

忽略规则必须显示其实际作用域：隐藏无效链接、排除孤立候选、忽略目标、忽略 occurrence，或排除图贡献。删除或停用规则后，投影应从同一权威索引重新计算。

## 6. 保存、错误与恢复

设置保存使用串行合并队列。正常的“已保存”状态不常驻占行；只有等待保存、正在保存或保存失败时显示状态：

- 快速连续编辑可以合并，但已开始的写入不能被静默取消。
- 保存失败时保留内存中的待保存设置并显示重试操作。
- 未来版本 schema 的 `data.json` 进入只读保护，避免旧插件覆盖新格式。
- 撤销仅针对刚创建的规则，不暗示已经修改 Vault 内容。

扫描错误和设置保存错误是不同状态，必须分别呈现。所有错误信息应给出下一步，而不是仅输出内部堆栈。

## 7. 可访问性与移动端

- 页签使用 `tablist`、`tab`、`tabpanel` 语义以及 roving tabindex。
- 支持左右方向键、Home、End，切换后保持合理焦点。
- 窄屏页签可横向滚动；RTL 布局保持顺序和图标含义正确。
- 粗指针目标至少 44 CSS 像素。
- 状态不能只依赖颜色；徽标和文本必须共同表达。
- 结果菜单、复选框和展开控件需要可读标签。

桌面真实宿主、Android 模拟器和物理设备是独立验收边界。自动化 DOM 测试不能替代任何真实宿主结论。
