Link Integrity는 Broken links와 Isolated files를 찾는 로컬 전용 읽기 전용 Obsidian 진단 플러그인입니다.

## 찾는 항목

잘못된 내부 참조, 고립 파일, 신뢰도가 낮은 결과와 선택적으로 예상된 고립 파일을 표시합니다. 자기 링크, 외부 URL, Bases 동적 쿼리는 그래프 간선을 만들지 않습니다.

## 설치

첫 공개 버전은 아직 출시되지 않았습니다. 격리된 개발 Vault에서 `main.js`, `manifest.json`, `styles.css`를 `.obsidian/plugins/link-integrity/`에 복사하세요. 업그레이드는 `data.json`을 보존합니다.

## 개인정보 및 데이터

모든 처리는 로컬에서 이루어집니다. Vault 내용을 전송하거나 수정하지 않고, 외부 URL을 검사하지 않으며, 파생 그래프를 저장하지 않습니다.

## 호환성

Obsidian 1.12.7 이상이 필요하며 데스크톱과 모바일을 대상으로 합니다.

## 상태

초기 로컬 구현 중이며 아직 게시, 태그 또는 마켓 등록이 없습니다.
