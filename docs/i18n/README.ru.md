Link Integrity — локальный плагин Obsidian только для чтения, который помогает находить Broken links и Isolated files.

## Возможности

- Находит внутренние ссылки на отсутствующие файлы, заголовки и блоки в Markdown, встраиваниях, Frontmatter, Canvas и явно указанных файловых ссылках Bases.
- Находит файлы без допустимых входящих и исходящих связей с другим существующим файлом Vault. Ссылки на себя и внешние URL не считаются связями внутри Vault.
- Отдельно предупреждает, если в изолированном файле есть неработающие исходящие ссылки, чтобы такой файл не выглядел очевидным кандидатом на удаление.
- Периодические заметки, шаблоны, архивы и похожие файлы можно пометить как Expected isolated. Это меняет только их категорию в результатах и не меняет реальные ссылки.
- Фильтрует изолированные файлы по типам Obsidian, форматам изображений, аудио, видео, PDF и настроенным расширениям вложений.
- При необходимости строит полный индекс и затем автоматически обновляет его при изменениях Vault.
- Открывает источник каждой найденной проблемы, когда точная навигация доступна. Проверка и индексирование выполняются локально.

Динамические результаты запросов Bases не считаются ссылками автоматически. Если целевой файл существует, но в нём нет нужного заголовка или блока, файлы всё равно считаются связанными, а отсутствующий заголовок или блок показывается отдельной ошибкой.

## Требования и совместимость

- Obsidian 1.12.7 или новее.
- Поддерживает настольную и мобильную версии Obsidian.
- Проверяется только текущий Vault. Внешние сайты и удалённые ресурсы не проверяются.

## Установка

Откройте **Настройки → Сторонние плагины → Обзор**, найдите **Link Integrity** и установите его. Если плагин ещё не отображается в каталоге, скачайте `link-integrity-<version>.zip` из [последнего выпуска GitHub](https://github.com/ZHYX91/obsidian-link-integrity/releases/latest).

Для ручной установки поместите `main.js`, `manifest.json` и `styles.css` в `Vault/.obsidian/plugins/link-integrity/`. При обновлении заменяйте только эти три файла и сохраняйте `data.json`, если не хотите сбросить настройки.

## Использование

1. Включите Link Integrity в сторонних плагинах.
2. Откройте Link Integrity с ленты или из палитры команд. В боковой панели есть **Broken links** и **Isolated files**.
3. Выберите результат, чтобы открыть его источник. Фильтры изолированных файлов меняют только текущий вид и не затрагивают сохранённые настройки по умолчанию.
4. Сканирование при запуске по умолчанию отключено. При открытии боковой панели индекс создаётся по необходимости; также можно использовать **Построить индекс** или **Перестроить индекс** в общих настройках. После первого успешного построения изменения Vault автоматически обновляют результаты.

## Настройки

- **Общие**: язык, сканирование при запуске, представления по умолчанию и команды построения/перестроения индекса. Язык по умолчанию — **Следовать Obsidian**.
- **Broken links**: какие ошибки показывать и какие именованные правила исключения использовать, с предварительным просмотром совпадений.
- **Isolated files**: типы файлов по умолчанию, необязательный режим без входящих ссылок, Expected isolated, правила исключения и правила ожидаемой изоляции.
- Правила ожидаемой изоляции могут сочетать тип файла, одну папку или папку с подпапками, форматы даты, glob-шаблоны и расширенные регулярные выражения. Предустановка периодических заметок поддерживает день, неделю, месяц, квартал и год.

Настройки и пользовательские правила хранятся в `data.json`. Рассчитанный индекс ссылок хранится только в памяти и после перезапуска создаётся заново.

## Ограничения

- Link Integrity не удаляет файлы, не переписывает ссылки и не решает автоматически, какие файлы нужно удалить.
- Внешние URL намеренно не проверяются и не запрашиваются по сети.
- Динамические результаты Bases не считаются прямыми связями между файлами; учитываются только явно указанные ссылки.
- Правила ожидаемой изоляции меняют только категорию уже изолированных файлов. Они не скрывают неработающие ссылки и не удаляют реальные связи.

## Конфиденциальность и безопасность

Индексирование и проверка правил выполняются локально. Link Integrity не загружает содержимое Vault, не требует учётной записи и не изменяет заметки. Пути и примеры диагностики остаются в текущем сеансе Obsidian, пока вы сами не решите ими поделиться.
