Link Integrity es un complemento de diagnóstico local y de solo lectura para Obsidian, centrado en Broken links e Isolated files.

## Qué detecta

Encuentra referencias internas no válidas, archivos aislados, resultados de baja confianza y, opcionalmente, archivos cuyo aislamiento es esperado. Los autoenlaces, URL externas y consultas dinámicas de Bases no crean aristas.

## Instalación

La primera versión pública aún no se ha publicado. En un Vault de desarrollo aislado, copia `main.js`, `manifest.json` y `styles.css` en `.obsidian/plugins/link-integrity/`. Las actualizaciones conservan `data.json`.

## Privacidad y datos

Todo se procesa localmente. El contenido del Vault no se envía ni modifica, no se comprueban URL externas y el grafo derivado no se persiste.

## Compatibilidad

Requiere Obsidian 1.12.7 o posterior y está pensado para escritorio y móvil.

## Estado

La implementación local inicial está en curso; todavía no hay publicación ni ficha en el mercado.
