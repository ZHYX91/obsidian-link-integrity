# Link Integrity 产品语义

本文定义 Link Integrity 当前产品行为。它描述用户能够依赖的诊断语义，不是进度清单或未来路线图。

## 产品定位

Link Integrity 是完全本地、只读的 Obsidian Vault 诊断插件。它提供两个业务视图：无效链接和孤立文件。插件帮助用户发现需要审查的链接关系，但默认不删除文件、不批量改写链接、不检查外部 URL，也不把“诊断结果”表达成自动清理许可。

## 有效 Vault 连接

有效连接是来源文件指向另一个当前存在 Vault 文件、且文件级目标已成功解析的显式内部引用。

- 自链接不连接两个文件，因此不计入有效入度或出度。
- 外部 URL 不属于 Vault 连接。
- 目标文件存在但标题或块缺失时，文件级连接仍然有效，同时产生标题或块无效诊断。
- 同一对文件之间的重复引用保留为独立诊断 occurrence；图同时保存按引用类型计数的边贡献。

当前贡献显式连接的来源包括：

- Markdown 正文内部链接和嵌入；
- Frontmatter 中 Obsidian 识别的内部链接；
- Canvas 显式文件节点、背景文件以及可解析文本中的内部链接；
- Bases 文件中的显式文件引用。

Bases 动态查询产生的结果不是显式引用，默认不创建图边。周期笔记日期相邻也不创建伪边。

## 无效链接

无效链接结果按 occurrence 报告，而不是只按目标汇总。当前确认的原因包括目标文件缺失、内部链接无效、标题缺失和块缺失。等待宿主元数据的链接不是已确认错误；无法验证的子路径也不会冒充已确认错误。

点击结果应打开来源，并在来源类型支持时定位到行、属性或 Canvas 节点。无法精确定位时，界面必须诚实降级为打开来源文件或节点。

普通的结果隐藏规则只改变诊断可见性，不改变文件之间的有效连接，也不抹去孤立结果上的风险信号。

## 孤立文件

文件在有效图中同时满足以下条件时，才是默认意义上的孤立文件：

- 与其他现有 Vault 文件没有有效入链；
- 与其他现有 Vault 文件没有有效出链。

只有无效出链的文件仍然满足此定义，因为无效引用没有连接到现有文件。此类结果必须显示“孤立 · 含 N 处无效链接”一类的低置信度状态，不得作为高置信度清理项。

“无入链文件”是独立的高级查询。它可以包含仍有有效出链的文件，因此不能替代默认孤立定义，也不能自动解释为无用文件。

## 预期孤立

某些文件按工作流设计本来就可能孤立，例如周期笔记、模板或导出物。预期孤立规则只对已经满足孤立定义的候选文件分类：

- 默认从孤立主列表、主计数和高置信度清理候选中排除；
- 用户可通过高级选项显示，并查看匹配规则；
- 不创建日期邻接或其他推测连接；
- 不影响无效链接诊断，也不移除真实图贡献。

一条规则可以组合文件类型、文件夹和命名条件。不同条件之间是 AND；同一规则中的多个日期格式、glob 或正则命名模式之间是 OR。规则保存名称，并可计算匹配数量和少量样例。内置周期笔记预设独立于 Chrono Notes 或其他插件运行，覆盖日、周、月、季和年格式，路径与命名格式均可配置。

## 范围与文件类型

Link Integrity 严格分离三种范围：

- 候选范围：哪些文件可以出现在孤立文件结果中；
- 诊断范围：哪些无效链接结果在界面中可见；
- 贡献范围：哪些有效引用参与图计算。

未选择的候选类型和普通隐藏规则仍然贡献有效连接。只有单独的高级“排除图贡献”规则会改变图，而且界面必须警告它可能制造假孤立结果。

孤立候选使用中心文件类型 registry：Obsidian 文件（Markdown、Bases、Canvas）、图片、音频、视频、版式文件（PDF）和其他附件。图片、音视频及附件按格式族细分，常见扩展名别名合并；匹配不区分大小写。未知附件只有在用户明确配置该自定义扩展名后才进入候选范围；选择“自定义”格式族但扩展名列表为空时，不能静默纳入所有未知文件。设置保存默认候选范围，侧栏筛选只是临时查询条件。

## 数据与安全边界

所有扫描、索引和规则匹配都在本地执行。初始版本只持久化设置、忽略规则和界面偏好，不持久化派生链接图。重启后重新建立当前 Vault 的权威索引。

插件的诊断模式是非破坏性的。自动删除、批量修复、外部 URL 网络检查以及把动态查询结果推断成显式连接，均不属于当前行为。

## 当前交付状态

核心语义、查询投影、全量与增量索引控制器以及自动测试已经在仓库中实现。首个版本仍处于本地实现和验收阶段，尚未发布。正式 Vault smoke 已验证 Obsidian 1.13.4 中本次观察到的桌面流程；Obsidian 1.12.7、Android 模拟器、物理设备及更完整的实时事件验收仍是独立证据边界。类型检查、单元测试、合成基准和一次桌面 smoke 都不能替代这些尚缺结论。
